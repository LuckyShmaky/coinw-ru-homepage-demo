# CoinW RU — демо новой главной

Статичный макет главной `coinw.com/ru_RU` после ребрендинга (документ «Rebranding CoinW», раздел Main page). Тестовый стенд для синхронизации с командой, не рабочий сайт: формы и кнопки не работают, страница закрыта от индексации.

Что изменено относительно текущей главной:

1. Новый слоган «Универсальная платформа для вашей торговли» (согласован 4 ноября 2026) и «до 12 000 USDT» в подзаголовке.
2. Лента анонсов акций (глобальные и СНГ) вместо бегущей строки с курсами.
3. Новый блок «Почему CoinW» с ключевыми преимуществами.
4. В «Нашем предложении» добавлены TradFi, CoinW Card и копитрейдинг.

Кнопка «Показать правки» в левом нижнем углу подсвечивает все изменения. Тексты акций и описания новых продуктов — черновики.
